Examples

Fourteen pages, no new components.

Reference compositions for Fieldwork, a fictional landscape practice. Each page is built only from Samla sections, components and patterns, with static fixture content.

  • Homepage

    Hero, logo rail, card grid, feature rows, media + content, stats, testimonial, CTA.

  • Standard content page

    Page header, article layout with contents, rich text and a data table.

  • Landing page

    Overlay header, media hero, steps, carousel, sticky FAQ, newsletter.

  • About

    Story split, values, stats, partners, gallery mosaic.

  • Services index

    Bordered service cards, process steps, logo grid.

  • Service detail

    Split page header, sticky split, focus areas, related carousel, FAQ.

  • Case studies index

    Listing with client-side filters, count and pagination.

  • Case study detail

    Project facts, narrative, video, gallery, results, related.

  • Articles index

    Featured article, link filters, sort dropdown, events list, newsletter.

  • Article detail

    Author, contents, long-form prose, related articles.

  • Contact

    Validated enquiry form, direct details, studio locations.

  • Team

    Profile cards in tabs by studio, careers list, application dialog.

  • Person

    Profile pattern, projects led, writing.

  • 404

    Narrow hero, search and popular links.
